# Boot test: ds41-1017-xq-v3-uncensored on Vast, 2026-10-22

The maintainer ran this test with `ablit up --trust verified` on their own Vast account. Host IDs, offer IDs, prices and keys are left out.

## Machine

One RTX 5090 with 32 GB of VRAM on a Vast verified host, with the pinned Xolotl image (`ghcr.io/jameselkins/ablit-xolotl@sha256:5c675f44...a204`). The image runs on this card through its `sm_120a` build.

The card has 8 GB more VRAM than the entry's 24 GB floor, so the 24 GB floor is still untested. The container's locked-memory limit was 8 MiB, and the engine started anyway.

## Stage times

| Stage | Time |
|---|---|
| Download and verify 371.7 GB, with the weight join running alongside | about 23 minutes, 1.8 to 2.1 Gbps |
| Engram tables | read in place from the official 1017 shards, no extraction |
| Rental created to ready | under 27 minutes |

## Results

1. Chat completions came back through the SSH tunnel. A 1,024-token answer took 30.9 seconds end to end, which is 33.1 tokens per second. The engine log reported 34 to 36 tokens per second while it generated, with an expert cache hit rate of 88.6 percent.
2. A request without the endpoint key got HTTP 401.
3. `ablit down` destroyed the machine and confirmed that billing stopped.

## Second run, 2026-10-23, Xolotl 03be8a6

The maintainer ran the entry again after the engine pin moved to Xolotl commit 03be8a6, with the image `ghcr.io/jameselkins/ablit-xolotl@sha256:064391fc...4884` and a 4096 MiB conversation cache.

1. The machine was one RTX PRO 6000 WS with 98 GB of VRAM on a Vast verified host. It downloaded 371.7 GB at about 4.4 Gbps and was ready about 14 minutes after the rental was created.
2. A 1,024-token answer took 19.6 seconds end to end, which is 52.2 tokens per second. The engine log reported 50 to 56 tokens per second, with an expert cache hit rate of 98.4 to 98.9 percent.
3. A request without the endpoint key got HTTP 401, and `ablit down` confirmed that billing stopped.

This card is larger than the RTX 5090 in the first run, so the two speeds do not measure the engine change alone. An earlier attempt on another host the same day never answered SSH, which led to the SSH deadline in `ablit up`.
