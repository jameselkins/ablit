# Clore notes

Clore is not in v1. ablit has no Clore driver and does not search or rent there.

Two facts about the marketplace explain why it needs separate work. Clore bills per minute, so a cost model that assumes hourly billing would misstate the total. Its prices are per day for the whole machine, so the ranking would need to compare a day price for a whole machine with an hourly price for the GPUs that a run needs.

A Clore driver is left for a later release. If you want to help, open an issue before you write code.
